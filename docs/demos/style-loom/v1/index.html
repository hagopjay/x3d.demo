Style Loom: one scene, twelve looks, one grammar

The neon night city had become the house style of the data demos. This page takes one data scene, the 260 nodes of X3D 4.0 as a city, and re-dresses it from a shared style vocabulary: ten parts of speech, fourteen rules a machine can check, four operators that make new styles from old ones. A style is a small JSON-LD document. The scene holds roles and data only. The compiler in this page joins them into X3D 4.0, and writes the style back into the file as Metadata, so the look is something you can hold an AI to.

The grammar what a style must say, and the rules it must obey



  
Sentence
Style    ::= Palette Surface Light Air Line Form Type Motion Encode View
Scene    ::= Role* , each Role carrying data (value, category, flags)
World    ::= compile(Scene, Style)            X3D 4.0 + Metadata

Style'   ::= transpose(Style, Style)          structure of one, palette of another
           | mix(Style, Style, t)             numbers and colours blend in OKLab
           | invert(Style)                    flip lightness: day becomes night
           | repair(Style)                    smallest lightness moves that satisfy the rules

valid(Style) ::= G1 ∧ G2 ∧ … ∧ G14            each rule measures, none guesses
