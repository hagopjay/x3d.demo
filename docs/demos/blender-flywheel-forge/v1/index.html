An agent builds. The gate says no. It learns.

A brass orrery, written as a Blender script by an AI agent (Claude, in this session) and exported to X3D 4.0. Every generation goes through the same eight checks, from the X3D schema to "does the browser frame look like Blender's?". Each next generation changes only what a check reported. All eight generations are kept on the record, including the beauty pass that regressed and the change that did nothing.

What the loop taught (all Confirmed on this rig)

LessonFound inRule for the next agent
The exporter keeps Blender's cast-shadow flag, so a lamp placed inside the Sun mesh exports as PointLight shadows="true" and X_ITE shadows the whole scene with the Sun itself.gen 0 → 1Turn shadows off for a lamp inside an emitter, or move it out.
Animation export is off unless use_animation=True is set: a keyframed scene exports frozen and still passes every validator.gen 0 → 1Always set it, and gate on motion.
Metallic 1.0 in X_ITE with no environment map shows only highlights, so the brass read black.gen 1 → 2Metallic around 0.7, or ship an environment.
Blender-made lights are capped at intensity 1 with no attenuation, so the browser lamp had no falloff and a fraction of Cycles' light.gen 2 → 3Set x3d_attenuation to 0 0 1 and x3d_energy_per_intensity (4π for a point lamp).
A glowing mesh lights the scene in Cycles but not in X3D, where emissiveColor lights nothing.gen 4 → 5Let the lamps carry the light; switch the emitter's diffuse visibility off in Cycles.
X_ITE 16.7.1 ignores a light's ambientIntensity under PhysicalMaterial: the frames came out byte-identical.gen 6 (dead end)Don't use ambientIntensity as bounce fill with PBR.
The exporter writes energy ÷ x3d_energy_per_intensity; x3d_intensity only marks the value as meant, so setting it alone changed nothing.gen 7, first tryCalibrate through the divisor.
The gate had two bugs of its own: a grey Cycles world the browser never draws, and a wall-clock motion check that flipped between 0.41 and 0.54 across runs.gen 2 and gen 1Gate the gate: black world, motion driven through SAI.
