# Sources and scope

The original IFC converter and corpus tools come from the user-supplied `files (69).zip`. Their original code and historical results are retained. New bridge, tests, art direction and fixture-generation code are in `studio/`.

The material baker, custom shader interface and display/GPU profiler build on the preceding Loomsong v4 work in this conversation. X_ITE 16.5.1 and the Cormorant Garamond font retain their bundled license files under `studio/vendor/`. The X3D schemas retain their original notices. Python dependencies retain their own upstream licenses and are installed separately.

No external photograph, HDRI capture or generated marketing image is used as a substitute for the rendered scene. Baked numerical textures and the IFC pavilion are generated by the included code. QA browser screenshots are external inspection intermediates and are not included in the release.
