Click the wall. Read its GlobalId.

A small timber, brick and concrete field station, authored as IFC4, and a site worker walking through it as an H-Anim 2.0 humanoid, in one X3D file built in Blender. Each wall, slab, column, beam, window and door keeps its IFC GlobalId and its quantities inside the X3D itself, as metadata. This page reads them live from the scene, checks each GlobalId against the IFC file, and colours the building by embodied carbon.

One identity, four places

2 · BlenderEach element's geometry becomes a mesh; its volume is measured there, and an x3d_metadata custom property holds GlobalId, class, material and quantities.
3 · X3D 4.0x3d-blender-io writes a MetadataSet on each element's Transform. x3d_mcp 39c6e94: XSD valid, 0 semantic errors, 0 warnings.
4 · This pageX_ITE reads the MetadataSet through SAI when you click, and the page looks the GlobalId up in station.ifc: checking.
