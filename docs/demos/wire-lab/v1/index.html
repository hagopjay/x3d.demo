The picture is drawn by X_ITE 16.7.1 from an X3D 4.0 file. The graph, the script and the X3D text are three views of the same thing: change one and the others follow. The node list comes from the X3D Unified Object Model (45 behaviour node types), through the same catalogue the Blender add-on x3d-blender-io uses, and the wiring rule here gives the same verdict as the add-on's Python on 55 shared cases (build/test_core.mjs). Download the file and import it into Blender with "Behaviour as node graph" ticked to see the same graph in Blender's node editor. Proof of concept. Checked in headless Chromium with software rendering only; no real GPU, phone or other browser was tried.
