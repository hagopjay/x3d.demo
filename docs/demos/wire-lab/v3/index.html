How this editor is built: one turn of the flywheel

  

  

  





  
The picture is drawn by X_ITE 16.7.1 from an X3D 4.0 file. The graph, the script and the X3D text are three views of the same thing, and so is the flywheel view. Every count on this page is a count of field callbacks X_ITE really made since the scene last loaded (editing a wire reloads the scene and starts the counts again); nothing is simulated, replayed or smoothed on the live lane. The Blender lane replays a file recorded once from the add-on's own simulator, on a different clock; it is labelled as such. Checked in headless Chromium with software rendering only; no real GPU, phone or other browser was tried. Proof of concept.
