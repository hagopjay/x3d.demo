Four physics engines, one X3D scene

The same RigidBodyPhysics file, stepped four ways. The first pane runs X_ITE's own Bullet live in your browser. The other three are recordings of the x3d.loom bridge's built-in engine, Rapier 0.21.0 (WASM) and cannon-es 0.20.0, each a script-free X3D file you can open on its own. Same bodies, same gravity, same friction, same bounce. The shapes of the heaps are not the same.

Scrub moves the three recordings together. The live pane keeps its own clock and shows its frame rate: X_ITE steps Bullet by the measured frame time (1 / max(10, fps)), so a slow page gives it long steps and it does not repeat run to run. It restarts when the recordings loop. Drag any pane to orbit it.

Best of 3, 720 steps, half spheres half boxes dropped on a floor. Chromium 153.0.8010.12 (SwiftShader build) and Node v22.23.4; the bridge runs in a browser, so the Chromium column is the one to read (Node's V8 flatters the WASM engine and punishes the pure-JS ones). results/speed.json.

Repeatable? Same on two hosts?

21 of 21 runs repeat bit for bit in one process (7 analytic scenes x built-in, Rapier, cannon-es), and stay equal when the frames arrive late or uneven (40 ms / 8.3 ms ticks), because the bridge steps a fixed 1/240 s grid.

Positions are bit-identical between Node 22 and Chromium 153 in 21 of 21 runs; orientation differs by at most 1.1e-16 (the two V8 builds round acos and atan2 differently).

X_ITE 16.6.0 / Bullet: the same drop gave a bounce apex of 0.784 m on the first load and 0.522 m on the second (Chromium 153, SwiftShader).

Does a CollisionSensor see the hit?

The adapter's contactMode: 'frame' merges the contacts of every sub-step of a tick. results/sensor-impact.json.

Wire it in

No bridge file is edited. The adapter replaces one function, BR.phys.tick, from its own file, and switching back to 'builtin' restores the original behaviour. Engines load only if their library is present.

<script type="module">
  import RAPIER from '@dimforge/rapier3d-compat'; import * as CANNON from 'cannon-es';
  await RAPIER.init(); window.__physLibs = { RAPIER, CANNON };
</script>
<script src="bridge.bundle.js"></script>                                         <!-- the bridge as built today -->
<script src="engines.js"></script><script src="engine-rapier.js"></script><script src="engine-cannon.js"></script>
<script>  __bridge.physEngines.use('rapier', { contactMode: 'frame' });  </script>   // 'builtin' | 'rapier' | 'cannon'
