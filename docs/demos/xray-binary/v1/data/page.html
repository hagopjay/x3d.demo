Method

The ledger follows the hypothesis-debugging loop described by ioma8 in “LLM assisted reverse engineering” (Slow Chronicle, 18 Nov 2026): one hypothesis, one definitive experiment, one recorded verdict, kept on disk. Here each row is code, each verdict is re-earned on this machine, and imported verdicts are display-only.
