# Data notice

The order-book and trade data in `downloads/kraken/` was polled from Kraken's public REST API on 2026-11-20. Kraken's Global Terms (https://www.kraken.com/legal/global-terms) appear to restrict making Kraken content available to third parties, so redistribution is not confirmed. The files are included only at the project owner's request and are removed promptly on request: open an issue at https://github.com/hagopjay/x3d.demo/issues titled `Takedown: orderbook-3d`. This project is not affiliated with Kraken, and this is not financial advice.

The README says the raw data stays local. That is not accurate; see [../../DATA-ATTRIBUTION.md](../../DATA-ATTRIBUTION.md).
