# Data notice

The order-book and trade data (formerly in `downloads/kraken/`) was polled from Kraken's public REST API on 2026-11-20. Kraken's Global Terms (https://www.kraken.com/legal/global-terms) appear to restrict making Kraken content available to third parties, so redistribution is not confirmed. The files are included only at the project owner's request and are removed promptly on request: open an issue at https://github.com/hagopjay/x3d.demo/issues titled `Takedown: orderbook-3d`. This project is not affiliated with Kraken, and this is not financial advice.

**Update 2026-11-22:** at the project owner's decision the raw files were removed from the repository tree. The derived scene and page remain. The files stay in earlier git history until it is purged. See [../../DATA-ATTRIBUTION.md](../../DATA-ATTRIBUTION.md).
