# Notice: geotiling v1

- **Page, builders, converter, tile files**: written for this site (x3d.demo), 18 Nov 2026. `build.py` regenerates `tiles/`, `tex/`, `gltf/`, `tileset.json`, `root.x3d`, `data/`; `tiles3d_to_x3d.py` regenerates `converted/`.
- **Satellite textures (`tex/z*.jpg`, the textures inside `gltf/*.glb`)**: derived from **Google Map Tiles API 2D satellite** tiles fetched on 11 Oct 2026 (68 tiles, 256 px, z7/z11/z13/z15; the planet-scale build's `data/sat*`). Attribution: "Imagery and data: Google". They are used here, at the owner's decision (18 Nov 2026), **for an academic, non-commercial proof of concept only**. Google's terms govern them; nothing here is a licence to redistribute or reuse them commercially, and Google's Map Tiles policies restrict caching and redistribution, so treat the committed copies as a risk the owner accepted, not as cleared. **Keep these images off the front page and out of any card still.** `python3 -I build.py --open-textures` rebuilds every tile with a hillshaded hypsometric tint made from the open terrain heights instead (no Google imagery); do that to publish beyond the PoC.
- **Drillfield 0.25 m DSM and orthophoto**: `drillfield-geo.x3d` loads `../../gobbler-worlds-within/v1/data/worlds/drillfield/drillfield.x3d` by Inline (no copy). Google Solar API dataLayers data (imagery 2019-06-02), same terms and same limits as above (see `heritage-geo/v1/NOTICE.md`).
- **Terrain heights**: AWS Terrain Tiles (terrarium PNG; sources include SRTM, USGS 3DEP, GMTED2010, ETOPO1). Open data; attribution kept here. Used for `GeoElevationGrid` heights.
- **Globe texture** `tex/earth_2048.jpg`: NASA Blue Marble, public domain, resized to 2048 x 1024.
- **3D Tiles**: the format is an OGC Community Standard (3D Tiles 1.1); `tileset.json` is generated here from the tiles above. Google's own Photorealistic 3D Tiles are **not** included: no tile bodies were ever stored, and Google's terms forbid caching them. The converter was dry-run only on a saved 64 KB root tileset (`gcp-showcase/key-trace/verify-2026-10-11-1615/3dtiles-root.json`, expired session token), which is not redistributed here.
- **X_ITE 16.6.0** is loaded from `../../blender-x3d-io/v1/vendor/x_ite/` (no copy).
- Numbers on the page carry their validator (`hagopjay/x3d_mcp` fa5dccf `validate_xml`) and viewer (X_ITE 16.6.0, headless Chromium, SwiftShader).
