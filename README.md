# x3d.demo

X3D demos in the order they were asked for, served on GitHub Pages from `docs/` on `main`.

- Front page: `docs/index.html` (newest copy of the demo doc).
- Every version of the doc: `docs/versions/vN/`. Every version of a demo: `docs/demos/<name>/vN/`. Changes go in `CHANGELOG.md`. Nothing is overwritten.
- To publish: Settings, Pages, deploy from branch `main`, folder `/docs`.
